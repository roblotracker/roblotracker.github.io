Who this covers

This policy covers the RobloTracker Discord application, the RobloTracker support server workflows described here, and this website. The RobloTracker team operates the bot independently. Discord, Roblox, and GitHub operate their own services under their own policies.

A member with the required Discord permissions chooses the Roblox profile to monitor. A profile may be monitored even when its Roblox account holder has never interacted with the bot. Publicly accessible profile information can still be personal information.

Information RobloTracker handles

Roblox profile and activity. Depending on tracker settings and the responses Roblox makes available, RobloTracker may store user IDs, username and display name, public bio and account attributes, name history, avatar and outfit data, public group roles, public presence, publicly returned experience details, and the time an observation was made. Public badges, creations, collections, favorites, and follower or following totals may also be available.

Friends. RobloTracker may use public friend counts and identities from a complete, validated API response. If Roblox limits the list, RobloTracker may display a count and retain previously saved entries as historical data. Named friend changes require enough reliable information to establish the change.

Discord configuration and activity. RobloTracker stores Discord server, channel, owner, and recipient IDs as needed to manage trackers, route alerts, apply permissions, or associate recorded events with their messages. Configuration can include monitored signals, alert cooldowns, recipient settings, and pause state.

Requests and tickets. A privacy request includes the Roblox account identifier, the requester’s Discord account ID, request reason, status, expiration, and a hash of the verification code. Support staff can read the text and attachments you voluntarily submit in a ticket. Share only the information needed for the request.

RobloTracker does not ask users for Roblox passwords or session cookies. It uses public API responses for tracking and does not seek private chats, private inventory contents, or payment details.

How we use the information

RobloTracker uses this information to establish baselines, compare later observations, display tracker details and history, deliver alerts, respect recipient choices, and diagnose failed checks or delivery. It also uses request information to verify control of a Roblox profile, review removal requests, and prevent an approved profile from being re-added.

Roblox chooses which details appear in API responses and may change, limit, or stop returning them. RobloTracker does not treat a missing response as evidence that an account deleted or changed information. An alert describes an observed change and may arrive after the activity itself.

Who can see tracker data

Tracker channels are configured for restricted access. Depending on the command, the tracker owner, authorized recipients, and server members with the required management permissions can see tracker details or history. Discord administrators and channel permission changes can affect who can read stored alert messages. A server can change its roles, permissions, or bot settings independently of RobloTracker.

Verified removal requests go to a restricted review channel in RobloTracker Support. The designated team and support-server administrators can access review information according to Discord permissions. Bug reports and suggestions use separate support tickets.

Hosting and service providers

Discord delivers commands, alerts, and support messages. Roblox supplies the public profile data used for tracking. RobloTracker’s hosting and configured database providers process operational data and may retain backups or logs under their own policies. Depending on the deployment, RobloTracker can use PostgreSQL or Supabase for primary storage, SQLite on a persistent host, and Turso for some archived alert details. The optional archive is not a complete copy of tracker data.

This is a static GitHub Pages website. It has no sign-in, contact form, first-party tracking scripts, or application cookies. GitHub may process technical request information to deliver and protect the site. Clicking an invite or support link opens Discord. Review each platform’s policy for how it handles your visits and account information.

Public usage totals

The website can display two aggregate figures when the service makes them available. The first counts distinct Roblox accounts with active trackers, so one account tracked in several servers counts once. The second counts Discord servers where the bot is installed, including those without an active tracker.

The statistics response contains these totals only. It contains no Roblox usernames or user IDs, Discord server or member IDs, channel data, or individual history. When the website fetches the totals from a separate service, that service receives the technical information needed to handle the request, including the browser's originating site.

Retention and copies

RobloTracker retains tracker configuration and the latest saved snapshot while the tracker exists. A server operator can use /untrack-account to stop tracking and remove that tracker’s current record. Alert history follows the deployment retention setting, which defaults to 30 days and can be configured from 14 to 365 days.

Previously delivered Discord messages, screenshots, forwarded alerts, or backups may remain separately. Optional archive cleanup can take longer when the archive is unavailable. RobloTracker cannot set the retention period for a provider’s backup copies or remove a screenshot or forwarded message someone else controls.

Request removal or ask about your data

Use the verified removal workflow in a Discord server that has RobloTracker and allows its privacy commands.

  1. Run /privacy remove with the Roblox username or ID and a short reason.
  2. Put the one-time code in that Roblox profile’s description so the bot can verify control. The description is public during this step. Keep the code out of tickets and chat.
  3. Run /privacy verify within 24 hours. Remove the code from the profile after verification.
  4. Run /privacy status to check progress while the request is still linked to your Discord account.

After successful verification, the team reviews the request. If approved, RobloTracker removes matching tracker records across servers, schedules best-effort cleanup of related RobloTracker channels and messages, and keeps a minimal Roblox ID block to prevent the profile from being added again. The application removes the requester link, username, and reason after acceptance. Declining a request leaves tracker data unchanged.

If you can’t use the command, need to act for a child, or want to ask about access or correction, open a private ticket in RobloTracker Support. Never submit a password, session cookie, or bot token.

Younger users and security

RobloTracker does not ask for age or independently confirm parental consent. Servers should use tracking responsibly and follow applicable rules for children’s data. Parents and authorized guardians can contact support for assistance with a request.

RobloTracker uses permission checks, restricted responses, mention allow-lists, and hashed verification codes to reduce exposure. These controls depend in part on server settings and services outside the team’s control. If you suspect unintended access or a misplaced alert, report it in a private support ticket and include only the relevant message link or details.

What comes from you, a server, or Roblox

Installing the bot supplies a Discord server context. Adding a tracker supplies a username or ID and the choices made in setup. Roblox returns the profile that matches the account lookup and the public data available for that profile. The account holder does not need to sign in to this site or authorize their Roblox account for a server to add the profile.

Server managers may change permissions or choose to share an alert. Those actions are under their control. If you see a private alert copied elsewhere, tell the moderators where it was reposted. If the underlying tracker is also a concern, use the removal workflow or contact RobloTracker Support.

Live checks, snapshots, and alerts

A snapshot is the information returned during an earlier check. RobloTracker saves snapshots so it can compare them with later observations. A change may result in an alert and a history item. A history item can describe an older state even after the live profile changes. Saved activity and current public presence have different meanings.

An API can return incomplete or stale information. This is especially relevant for friends, inventories, badges, game details, and session duration. RobloTracker can show that a value is unavailable, omit an alert, or retain an older observation. For a correction request, tell us which tracker or message showed the disputed information and what part looks wrong.

What happens during verification

RobloTracker issues a code tied to a request and checks whether the code appears in the Roblox profile description. It does not ask you to grant account access, sign in through a third-party form, or change your password. Use only the code shown privately inside the verified RobloTracker bot response. The team does not need a screenshot of your Roblox security settings.

If your request expires or the check cannot reach Roblox, follow the message shown by the bot. A successful check and the team’s decision are separate steps. If you can’t edit the profile, are acting for someone else, or need another way to explain your request, ask support privately. Provide enough context to locate the account and avoid posting details in public chat.

What to expect after a deletion request

Untracking stops one tracker in one Discord server. An approved profile-removal request is intended to remove that Roblox profile from tracking across RobloTracker’s servers and block it from being added again. Related Discord cleanup depends on the bot being able to reach the affected channels and messages. A blocked profile can still be visible directly on Roblox.

If an alert remains after a request is approved, send the message link privately so staff can check whether the bot can still access and remove it. Platform backups, copies saved by others, and content maintained by another service are governed separately.

What to include in a private ticket

For a privacy question or correction, include your Roblox profile link or ID and a short description of what you’re asking for. If an issue concerns a Discord message, include its link when you can do so safely. Tell staff if you cannot use the automated command or if you are contacting them on behalf of another person.

Information in a ticket remains subject to Discord’s channel permissions and data handling. Avoid attaching identity documents, credentials, or unrelated conversation history. Depending on where you live, you may have rights to ask about access, correction, removal, or use of your personal information. Private support is the contact route for those requests.

Changes and contact

We update this page when how the website or bot handles data changes. The date above identifies this version. For privacy questions, removal help, or reports of misuse, contact the team through RobloTracker Support and use #ticket-system.
