Follow a play session

/join-game

See public online, offline, Studio, and in-game changes. If Roblox returns the experience, RT can include its name or a link. Session lengths are estimates from observed activity.

In Discord Enable activity alerts in /settings. Use /join-game to check the current public status.

Spot a profile or avatar change

/track-info

Follow changes to usernames, display names, bios, and avatars. Some avatar alerts include a before-and-after image when both renders are available.

In Discord Open /track-info to see what RT last observed for the profile.

Browse friends, badges, and collections

/track-info

Explore public friends, badges, groups, outfits, and favorite experiences. Roblox may return only the friend count. RT uses complete lists for named friend alerts.

In Discord Open /track-info and choose the Friends or Badges section.

Choose what gets a ping

/alerts settings

Each tracker has its own Discord channel. You can set a cooldown, pick which changes can mention people, and assign the primary recipient.

In Discord Use /alerts settings to change delivery and /alerts recipients list to check the recipients.

Find an earlier alert

/user-history

Review delivered alerts by profile or check which monitors are still getting data. Server managers can see whether alert channels are reachable.

In Discord Use /user-history for saved changes and /status for service checks.

Request removal of a profile

Data removal guide

If you control a tracked Roblox profile, you can verify it and ask RT’s team to review a removal request.

In Discord Start with /privacy remove, then follow /privacy verify and check /privacy status.

Set up a tracker

You’ll need permission to manage the Discord server where you want alerts.

  1. Install RobloTracker

    Review the permissions, then choose your server on Discord.

  2. Run /setup

    Check that RobloTracker can create and configure tracker channels.

  3. Run /track-account

    Enter a Roblox username or ID, confirm the profile, and choose what to follow.

  4. Set your alerts

    Use /alerts settings to adjust delivery and /alerts recipients list to see who gets pinged.

Common questions

Why is a friend list or game missing?

Roblox sometimes sends only a friend count or a presence status. Your signed-in Roblox view may show details the public API leaves out.

Why didn’t I get an alert right away?

The first check gives RobloTracker a starting point. Later alerts depend on Roblox responding, the tracker’s cooldown, and whether RobloTracker can send to the Discord channel.

Does RobloTracker need Administrator?

The install requests specific permissions, including Manage Channels and Manage Roles for tracker setup. Review the channel’s access after setup.

How do I remove my profile?

Start with /privacy remove in a server that has RobloTracker or use the removal guide. For help or to report misuse, open a private support ticket.

Need a hand?

Open a private ticket in #ticket-system. For an outage or a release note, check #bot-downstatus or #bot-updatelog.
