Roblox activity

/join-game

See when a tracked profile comes online, starts or leaves an experience, goes offline, or opens Studio. Session lengths are estimates based on the checks RT receives.

  • Public presence and game details
  • Game links when Roblox provides them

Profile and avatar

/track-info

Follow username, display name, bio, and avatar changes. When images are available, some alerts include an experience preview or a before-and-after avatar comparison.

  • Names, bios, and profile links
  • Avatar renders, worn items, and outfits

Friends and collections

/track-info

Browse public friends, badges, groups, favorite experiences, and item collections when Roblox makes them available. Friend totals can appear on their own. Named friend alerts require a complete list.

  • Friend counts and verified named changes
  • Public collections and group roles

Alert delivery

/alerts settings

RT creates a private tracker channel for each account. Choose which changes can ping, set a cooldown, add or remove recipients, and pick a primary recipient. Server managers can set defaults for new trackers.

  • Per-account monitors and recipients
  • Channel repair with saved settings

History and health

/user-history

Page through delivered alerts for a profile. Server managers can check which monitors are getting data and whether RT can reach each alert channel.

  • Saved changes and tracker capacity
  • Monitor and delivery checks

Privacy controls

Data removal guide

RT reads public Roblox data. Account holders can verify their profile and request removal through the bot. The support team reviews verified requests in a restricted channel.

  • Profile verification
  • Private request status

Set up a tracker

You’ll need permission to manage the Discord server where you want alerts.

  1. Add RobloTracker

    Pick your server in Discord and review the requested permissions.

  2. Run /setup

    Check that RobloTracker can create and configure tracker channels.

  3. Run /track-account

    Enter a Roblox username or ID, confirm the profile, and choose what to follow.

  4. Set your alerts

    Use /alerts settings to adjust delivery and /alerts recipients list to see who gets pinged.

Common questions

Why is a friend list or game missing?

Roblox sometimes sends only a friend count or a presence status. Your signed-in Roblox view may show details the public API leaves out.

Why didn’t I get an alert right away?

The first check gives RobloTracker a starting point. Later alerts depend on Roblox responding, the tracker’s cooldown, and whether RobloTracker can send to the Discord channel.

Does RobloTracker need Administrator?

The install requests specific permissions, including Manage Channels and Manage Roles for tracker setup. Review the channel’s access after setup.

How do I remove my profile?

Start with /privacy remove in a server that has RobloTracker or use the removal guide. For help or to report misuse, open a private support ticket.

Need a hand?

Open a private ticket in #ticket-system. For an outage or a release note, check #bot-downstatus or #bot-updatelog.
