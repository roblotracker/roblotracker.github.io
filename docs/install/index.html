After you add RT

Set up your first tracker in Discord.

See the full setup guide

  1. Check permissions

    Run /setup to check that RT can create tracker channels.

  2. Add a Roblox profile

    Use /track-account with a Roblox username or ID.

  3. Choose who gets pinged

    Open /alerts settings to control which updates notify your team.
