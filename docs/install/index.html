From install to first alert

Once Discord confirms the install, return to your server and run these commands.

  1. Check your server

    /setup

    Check channel permissions so RT can create the tracker.

  2. Add a Roblox profile

    /track-account

    Enter a username or ID, then choose which changes you want to follow.

  3. Choose when to ping

    /alerts settings

    Pick the alerts that can mention your saved recipients.

What permissions does RT request?

Review the requested permissions in Discord before you authorize. The invite does not request Administrator.

Manage Channels and Roles
Create tracker channels and set access for recipients.
View Channels, Send Messages, and Read Message History
Deliver alerts and find earlier messages as needed.
Embed Links, Attach Files, and Use External Emojis
Show profile links, alert images, and RT icons.
Manage Messages
Remove related alert messages during supported cleanup.

Can’t see your server?

Switch to the Discord account that manages the server. If you can see your server but authorization fails, check the role permissions in that server.
