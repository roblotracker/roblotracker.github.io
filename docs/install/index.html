Install RobloTracker for Discord.

Choose a server you manage, review the permissions in Discord, and set up your first Roblox tracker.

Continue to Discord

You’ll authorize RobloTracker on Discord. A Roblox login is unnecessary.

What RT needs access to

Manage Channels and Roles
Create tracker channels and set access for their recipients.
View Channels, Send Messages, and Read Message History
Send alerts and find earlier messages when needed.
Embed Links, Attach Files, and Use External Emojis
Include links and images in alerts and command screens.
Manage Messages
Remove related alert messages during supported cleanup.

Your first tracker

Run these commands in the server where you installed RT.

  1. /setup

    Check that RT has the permissions it needs.

  2. /track-account

    Enter the Roblox username or ID and pick the changes you want to watch.

  3. /alerts settings

    Choose which changes can ping your saved recipients.

Can’t see your server?

Check that you’re signed into the right Discord account and have permission to manage the server.
